### NBT round trip

The test summoned one Happy Ghast and one cow at separate positions. Both were
given source-style `home_pos` and `home_radius` commands before saving.

Before save, the Happy Ghast exposed `home_pos=[I; 5, 90, 5]` and
`home_radius=32`; the cow had no `home_pos` or `home_radius` tags. After
`save-all flush`, a clean stop, and a fresh server start, the Happy Ghast still
had exactly the same home position and radius and remained at its original
position. The cow still had neither tag and remained at its original position.

This is both the persistence check and the negative control showing that the
compatibility logic is scoped to the Happy Ghast entity type.

## Static client closure

The compiled client subscriber is annotated with
`@EventBusSubscriber(modid="happyghast_equivalence", value=Dist.CLIENT)` and
handles NeoForge `CalculateDetachedCameraDistanceEvent`. It checks the root
vehicle registry id and sets distance to `8.0F` only for `minecraft:happy_ghast`.
`javap` confirms the event handler and annotation in the final JAR.

The two temptation hooks are also present in bytecode: `TemptGoal` changes its
targeting condition to range 16 for Happy Ghast only, while `TemptingSensor`
redirects both its targeting-condition test and its hard-coded `closerThan`
distance. Other mobs retain the original values.

## Release gate / remaining scope

Dedicated smoke cannot exercise a graphical third-person camera. A client
launch with a player mounted on a Happy Ghast must still be run before release
to verify the visible camera distance is 8 blocks. A real player temptation
interaction should also be checked in that client session. This companion does
not implement the separate 1.21.11 locator/waypoint transmit-range feature.

Run the remaining client gate in an open, flat area with Backport 1.5 and the
exact artifact hash above:

1. Summon a test entity with
   `/summon minecraft:happy_ghast ~ ~2 ~ {Tags:["hgeq_camera"]}`.
2. Mount it with
   `/ride @s mount @e[type=minecraft:happy_ghast,tag=hgeq_camera,limit=1,sort=nearest]`.
3. Cycle through rear third person, front third person, and first person. Both
   detached views must use the unoccluded 8-block distance without a crash or
   camera jump. After dismounting, ordinary entities must retain the vanilla
   4-block detached distance.
4. In survival mode, hold a snowball first at a clear 15-to-16-block distance,
   then beyond 16 blocks. The Happy Ghast must
   acquire/follow the player in the first case and must not do so in the second.
   Repeat once with the adult and once with a baby summoned using
   `/summon minecraft:happy_ghast ~ ~2 ~ {Age:-24000}` to cover both TemptGoal
   and TemptingSensor paths.
5. Save, exit the client, and rejoin. Confirm the client log contains no mixin
   application error and that the existing `home_pos`/`home_radius` check still
