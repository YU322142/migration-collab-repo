# Hot Bath Mod 测试清单 (Test Checklist)

## 1. 核心功能测试 (Core Functionality - No Extra Mods)

_测试仅安装 Hot Bath mod 时的基础功能_

### 1.1 浴水瓶药水效果 (Bath Water Bottle Effects)

#### 1.1.1 热水瓶 (Hot Water Bottle)

- [ ] 饮用后获得速度 I 效果（45 秒）

#### 1.1.2 蜂蜜浴水瓶 (Honey Bath Water Bottle)

- [ ] 饮用后获得伤害吸收 I 效果（45 秒）

#### 1.1.3 牛奶浴水瓶 (Milk Bath Water Bottle)

- [ ] 饮用后随机移除 1 个负面效果

#### 1.1.4 草药浴水瓶 (Herbal Bath Water Bottle)

- [ ] 饮用后恢复 3 心生命值
- [ ] 饮用后获得抗性提升 I 效果（45 秒）

#### 1.1.5 牡丹浴水瓶 (Peony Bath Water Bottle)

- [ ] 饮用后获得幸运 I 效果（45 秒）

#### 1.1.6 玫瑰浴水瓶 (Rose Bath Water Bottle)

- [ ] 饮用后获得力量 I 效果（45 秒）

### 1.2 喷溅型浴水瓶效果 (Splash Bath Water Bottle Effects)

- [ ] 投掷后有抛物线轨迹（重力 0.05）
- [ ] 撞击方块或实体后破碎，播放破碎音效
- [ ] 破碎处生成对应的液体粒子和气泡粒子
- [ ] 破碎处生成物品碎片粒子
- [ ] **重要**：被喷溅到的玩家有获得温度效果（有 WARM/36°C/30 秒的御寒 2 级）
- [ ] 喷溅型热水瓶：给予速度 II (30 秒)
- [ ] 喷溅型蜂蜜浴水瓶：伤害吸收 II (30 秒)
- [ ] 喷溅型牛奶浴水瓶：移除 2 个负面效果
- [ ] 喷溅型草药浴水瓶：给予抗性提升 II (30 秒) 并恢复 2 心生命值
- [ ] 喷溅型牡丹浴水瓶：给予幸运 II (30 秒)
- [ ] 喷溅型玫瑰浴水瓶：力量 II (30 秒)

### 1.3 液体方块交互 (Fluid Block Interactions)

- [ ] **气泡柱**：灵魂沙在液体下方产生上升气泡柱
- [ ] **气泡柱**：岩浆块在液体下方产生下沉气泡柱（漩涡）
- [ ] **气泡柱**：实体在气泡柱中受到推力/拉力影响
- [ ] **气泡柱**：气泡柱使用的是自定义气泡粒子（对应液体颜色/材质）
- [ ] **滴水石锥**：液体源头下方有滴水石锥时，会产生滴水粒子
- [ ] **入水气泡**：玩家进入液体时，水面产生自定义气泡粒子
- [ ] **入水气泡**：气泡数量随入水高度（摔落距离）增加，有上限
- [ ] **入水气泡**：气泡有向四周扩散并下沉后上浮的动画效果

### 1.4 基础稳定性 (Basic Stability)

- [ ] 所有浴水瓶的药水效果正常工作
- [ ] 游戏正常运行，无崩溃
- [ ] 多个玩家同时饮用浴水瓶，药水效果互不干扰

## 2. 模组集成：ToughAsNails (Mod Integration: ToughAsNails)

_仅在安装 ToughAsNails mod 时测试_

### 2.1 浴水瓶温度效果

- [ ] 饮用后温度变为 WARM（10 秒）
- [ ] 温度效果持续 10 秒后消失
- [ ] 10 秒后温度恢复到正常状态
- [ ] 在温度效果激活期间再次饮用浴水瓶，时间重置为 10 秒
- [ ] 多次连续饮用，每次都重置为 10 秒

### 2.2 HotBath 方块右键喝水 (Right-Click Drinking)

- [ ] 在热水 HotBath 方块中潜行 + 主手空着 + 右键，可以喝水
- [ ] 喝水后恢复口渴值 (TAN Thirst)
- [ ] 喝水后获得温暖效果（10 秒 WARM）
- [ ] [Cold Sweat] 若安装，同时获得 36°C 体温效果 (5 秒)
- [ ] [LSO] 若安装，同时获得 HOT_DRINK 效果并恢复 LSO 口渴值
- [ ] 在不同类型 HotBath 方块（蜂蜜、牛奶等）中右键喝水，效果一致（只有温度，无药水效果）
- [ ] 右键喝水不会获得速度、力量等药水效果，也不会恢复生命值

### 2.3 HotBath 方块环境温度

- [ ] 玩家在热水 HotBath 方块中时，温度显示为 WARM
- [ ] 所有类型 HotBath 方块都提供 WARM 温度效果
- [ ] 在 HotBath 方块中饮用浴水瓶，两种温度效果可以共存
- [ ] 离开 HotBath 方块后，浴水瓶的温度效果继续生效 10 秒

### 2.4 边界情况

- [ ] 玩家在温度效果激活期间退出游戏，重连后效果清除
- [ ] 玩家在温度效果激活期间死亡，重生后效果清除
- [ ] 多玩家同时测试，温度效果独立计时

### 2.5 基础兼容性

- [ ] 游戏启动时日志显示成功注册温度修改器
- [ ] 移除 ToughAsNails mod 后游戏仍能正常运行

## 3. 模组集成：Cold Sweat (Mod Integration: Cold Sweat)

_仅在安装 Cold Sweat mod 时测试_

### 3.1 浴水瓶温度效果

- [ ] 饮用后体温升至 36°C（20 秒）
- [ ] 如果环境温度高于 36°C，无温度变化
- [ ] 温度效果持续 20 秒后消失
- [ ] 20 秒后体温恢复到正常状态
- [ ] 在温度效果激活期间再次饮用浴水瓶，时间重置为 20 秒

### 3.2 HotBath 方块环境温度

- [ ] 玩家在热水 HotBath 方块中时，体温升至约 37°C（体温舒适区）
- [ ] 离开 HotBath 方块后，体温逐渐恢复到环境温度
- [ ] 在寒冷生物群系（如雪原）中，HotBath 方块有效提供温暖
- [ ] 在极寒天气中，HotBath 方块可以防止玩家冻伤
- [ ] 在炎热生物群系（如沙漠）中，HotBath 方块温度不会让玩家过热
- [ ] HotBath 方块周围 7 格范围内都能感受到温暖效果（距离越远效果越弱）
- [ ] 所有类型 HotBath 方块都提供相同的温度效果

### 3.3 交互叠加

- [ ] 在 HotBath 方块中饮用浴水瓶，浴水瓶的 36°C 效果可以覆盖 HotBath 方块的 37°C
- [ ] 离开 HotBath 方块后，浴水瓶的温度效果继续生效 5 秒
- [ ] [与 TAN 共存] 饮用浴水瓶或右键喝水，同时获得两种温度效果（TAN: 10 秒, Cold Sweat: 5 秒 36°C）

### 3.4 基础兼容性

- [ ] 游戏启动时日志显示成功注册温度修改器
- [ ] 移除 Cold Sweat mod 后游戏仍能正常运行
- [ ] 多玩家同时在 HotBath 方块中，各自体温独立调节

## 4. 模组集成：Legendary Survival Overhaul (Mod Integration: LSO)

_仅在安装 Legendary Survival Overhaul mod 时测试_

### 4.1 浴水瓶效果

- [ ] 饮用后恢复口渴值 (5 Hydration, 0.5 Saturation)
- [ ] 饮用后获得 HOT_DRINK 效果 (Level 1, 15 秒)
- [ ] 浴水瓶显示口渴值 Tooltip (水滴图标)
- [ ] 正常状态下饮用：获得 HOT_DRINK Level 1
- [ ] 在 HotBath 方块中饮用：获得 HOT_DRINK Level 3 (Amplifier 2)
- [ ] 离开 HotBath 方块后，HOT_DRINK 效果继续生效 15 秒
- [ ] [与 TAN 共存] 右键喝水也能获得 HOT_DRINK 效果并恢复 LSO 口渴值

### 4.2 HotBath 方块环境效果

- [ ] 玩家在热水 HotBath 方块中获得 COLD_RESISTANCE Level 3 (抗寒)
- [ ] 抗寒效果每 10 秒增加 1 分钟时长，上限 5 分钟
- [ ] 玩家在寒冷环境 (<16°C) 的热水 HotBath 方块中获得 TEMPERATURE_IMMUNITY Level 1
- [ ] TEMPERATURE_IMMUNITY 效果在进入 HotBath 方块 10 秒后开始生效
- [ ] 所有类型 HotBath 方块都提供相同的抗寒和温度免疫效果

### 4.3 基础兼容性

- [ ] 游戏启动时日志显示成功注册 LSO 处理器
- [ ] 移除 LSO mod 后游戏仍能正常运行
- [ ] 多玩家同时在 HotBath 方块中，各自效果独立

## 5. 原始物品与配方测试 (Items & Recipes)

### 5.1 物品获取 (Item Acquisition)

- [ ] 交易：新手级农民村民出售洗浴用药草 (10 绿宝石)
- [ ] 交易：流浪商人出售洗浴用药草 (15 绿宝石)
- [ ] 配方：热水桶 (水桶 + 燃料烧炼)
- [ ] 配方：牛奶浴桶 (热水桶 + 牛奶桶)
- [ ] 配方：中草药浴桶 (热水桶 + 2x 洗浴用药草)
- [ ] 配方：牡丹浴桶 (热水桶 + 2x 牡丹)
- [ ] 配方：蜂蜜浴桶 (热水桶 + 蜜脾块)
- [ ] 配方：玫瑰浴桶 (热水桶 + 8x 玫瑰丛)

### 5.2 液体方块限制 (Block Restrictions)

- [ ] 伤害：热带鱼以外的鱼类在 HotBath 方块中受到伤害
- [ ] 伤害：章鱼在 HotBath 方块中受到伤害
- [ ] 生成：水生生物不会在 HotBath 方块中自然生成
- [ ] 放置：无法在 HotBath 中放置珊瑚植物
- [ ] 放置：无法在 HotBath 中放置潮涌核心
- [ ] 放置：无法在 HotBath 中放置地表植物
- [ ] 放置：无法在 HotBath 中放置海草
- [ ] 钓鱼：在 HotBath 方块中钓鱼无法获得物品

### 5.3 液体功效测试 (Liquid Effects)

#### 5.3.1 热水 (Hot Water)

- [ ] 隐藏进度 [牛奶肌]：浸泡 100 次获得 100 经验

#### 5.3.3 中草药浴 (Herbal Bath)

- [ ] 亡灵生物伤害：0.5 点 / 秒
- [ ] 隐藏进度 [药罐子]：浸泡 100 次获得 100 经验

#### 5.3.4 牡丹浴 (Peony Bath)

- [ ] 浸泡 15 秒移除所有负面效果及不祥之兆
